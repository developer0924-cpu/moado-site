개인정보처리방침

시행일 2026년 11월 7일

워치비서(이하 “앱”)는 대표님의 회의·통화·메시지를 정리해 드리는 개인 업무 비서입니다. 앱은 정리에 꼭 필요한 정보만 다루며, 정보를 판매하거나 광고에 쓰지 않습니다.

1. 다루는 정보

  • 음성 녹음 — 사용자가 녹음 버튼을 누르거나 직접 켠 경우에만 녹음합니다.
  • 받아쓴 글·요약 — 녹음을 글로 바꾸고 요약한 내용입니다.
  • 알림 내용 — 사용자가 고른 카카오톡 대화방과 문자 알림의 보낸 사람·내용. 휴대폰 안에만 48시간 보관하고 자동 삭제합니다.
  • 일정·연락처 — 회의와 일정을 짝짓고 이름을 맞추기 위해 휴대폰 안에서 읽기만 합니다.
  • 메일 — 사용자가 연결한 경우, 답장이 필요한 메일의 제목·보낸 사람·요지를 읽습니다.

2. 정보를 쓰는 곳

정리 결과는 사용자 본인의 구글 드라이브·노션·캘린더에 저장됩니다. 앱 운영자가 따로 모아 두는 서버는 없습니다.

받아쓰기와 요약을 위해 필요한 부분만 아래 AI 서비스로 보내며, 각 서비스는 결과를 돌려준 뒤 학습에 쓰지 않는 유료 API로 사용합니다.

  • Anthropic(Claude), OpenAI, Google(Gemini), DeepInfra — 받아쓰기·요약·답장 초안
  • Kakao — 사용자가 연결한 경우 ‘나에게 보내기’ 메시지 발송

카카오톡·문자 내용은 사용자가 답장 초안을 요청한 그 한 건만 AI로 보냅니다.

3. 보내기 원칙

다른 사람에게 가는 메일·메시지는 앱이 스스로 보내지 않습니다. 앱은 초안만 만들고, 마지막 보내기 버튼은 사용자가 직접 누릅니다.

4. 보관과 삭제

  • 휴대폰 안 알림 내용: 48시간 뒤 자동 삭제
  • 녹음 파일·정리 결과: 사용자의 드라이브·노션에 저장되며, 사용자가 언제든 직접 지울 수 있습니다.
  • 앱을 지우면 휴대폰 안에 남은 정보도 함께 지워집니다.

5. 사용자의 선택

앱 설정에서 대화방 선택, 알림 읽기, 상시 녹음, 메일 연결을 언제든 끄거나 켤 수 있습니다. 휴대폰 설정에서 마이크·알림 접근·일정·연락처 권한을 거둘 수도 있습니다.

6. 아이의 정보

앱은 사업하는 성인을 위한 서비스이며, 만 14세 미만 아동의 정보를 일부러 모으지 않습니다.
